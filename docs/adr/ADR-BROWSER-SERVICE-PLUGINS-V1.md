# ADR: Browser Service Plugins Architecture, Experimental Contracts, and Failure Isolation (v1)

Статус: accepted  
Change: C-BROWSER-TABS-HISTORY-SERVICES-20260901  
Рубеж: M1.3 — Browser service plugins  

---

## 1. Context and Problem Statement

Рубеж M1.2 предоставил промышленный движковый провайдер (`worldline-browser-provider`, `worldline-browser-cef`, `worldline-browser-provider-process`), логические идентификаторы `ContextId` / `PageId`, навигацию, типизированные события ядра, версионированные ревизии (`DocumentRevision`), изоляцию хранилищ и сквозной проверочный срез S2.

Однако в Worldline до сих пор отсутствовали пользовательские сервисы браузера:
1. **Модель вкладок (`tabs`):** `PageId` — это идентификатор низкоуровневой поверхности страницы в движке, а не вкладка. Пользовательская вкладка обладает собственным жизненным циклом, порядком, группировкой, закреплением (`pinned`) и выделением.
2. **Долговременная история (`history`):** Стек `back/forward` в Chromium — это внутренняя структура навигации движка для перемещения по сессии, а журнал событий (`EventJournal`) ядра — это транспортный буфер. Ни тот, ни другой не являются долговременной транзакционной базой истории пользователя с возможностями поиска, дедупликации и независимой очистки.
3. **Монолитный риск:** Попытка реализовать все сервисы M1.3 (вкладки, историю, загрузки, куки, политики блокировки, поиск, DevTools) в одном неделимом изменении смешала бы непересекающиеся домены полномочий, транзакционные хранилища и границы сбоев.

Первый срез M1.3 формирует общую сервисную архитектуру плагинов браузера и реализует два наименее связанных сервиса: вкладки (`browser.tabs`) и историю (`browser.history`).

## 2. Browser Service Plugin Architecture and Anti-Corruption Boundary

Сервисы браузера в Worldline — это **обычные стандартные плагины**, функционирующие в собственных областях жизненного цикла (`LifecycleScopeId`) поверх существующего ядра:

```text
       ┌─────────────────────────────────────────────────────────┐
       │             Worldline Host Process (Microkernel)        │
       │   Capability Broker | Event Transport | State Storage   │
       └──────────────┬───────────────────────────┬──────────────┘
                      │ Capability RPC            │ Event Subscription
       ═══════════════╪═══════════════════════════╪═══════════════════════
         Service Anti-Corruption Boundary        │
       ═══════════════╪═══════════════════════════╪═══════════════════════
                      ▼                           ▼
       ┌───────────────────────────┐ ┌───────────────────────────┐
       │  Tabs Service Plugin      │ │  History Service Plugin   │
       │  - TabId / TabGroupId     │ │  - HistoryEntryId Store   │
       │  - Ordering / Pinning     │ │  - Idempotent Deduplication│
       │  - Detach-only Semantics  │ │  - Title Enrichment via   │
       │  - Transactional State    │ │    browser.page.ready     │
       └──────────────┬────────────┘ └────────────┬──────────────┘
                      │ Capability RPC (PageId)   │ Observe Events
                      ▼                           ▼
       ┌─────────────────────────────────────────────────────────┐
       │       Browser Engine Provider (M1.2 Native Plugin)      │
       │  - ContextId / PageId / DocumentRevision Lifecycle      │
       │  - CEF Native Window / Headful Navigation               │
       └─────────────────────────────────────────────────────────┘
```

### 2.1 Архитектурные инварианты сервисов
1. **Никакой браузерной политики в ядре:** Ядро Worldline не содержит понятий `Tab`, `TabId`, `HistoryEntry`, `Bookmark` или специальных привилегированных интерфейсов.
2. **CEF и провайдер изолированы от сервисов:** Провайдер движка (`worldline-browser-provider`, `worldline-browser-cef`) не зависит от `TabId`, `HistoryEntryId` или реализаций плагинов вкладок и истории.
3. **EVENT BUS IS NOT RPC:** Сервис истории наблюдает за навигацией через типизированный транспорт событий (`browser.navigation.committed`, `browser.page.ready`), но события никогда не инициируют навигацию и не заменяют вызовы Capability RPC.
4. **Разделение полномочий:** Владение `TabId` или чтение истории не предоставляет прав `NavigatePage`, `ActOnPage`, `QueryDocument` или `ControlDownload`.

## 3. Experimental Contract Stability Policy (v0.1)

Все новые контракты сервисов браузера вводятся как **экспериментальные версии 0.1** в изолированном контейнере `worldline-browser-services-contract`:

| Контракт | Версия | Статус | Операции | Необходимые права |
|---|---|---|---|---|
| `browser.tabs` | `0.1` | Experimental | `create`, `list`, `get`, `select`, `move`, `pin`, `group`, `ungroup`, `close` | `browser.tabs.read` (чтение/список), `browser.tabs.mutate` (модификация) |
| `browser.history` | `0.1` | Experimental | `query`, `get`, `delete`, `clear` | `browser.history.read` (поиск/чтение), `browser.history.delete` (удаление/очистка) |

### 3.1 Правила стабильности
1. Экспериментальные контракты 0.1 могут уточняться на основе опыта интеграции с пользовательским интерфейсом (M1.4) без нарушения гарантий стабильности ядра.
2. Базовые стабильные контракты движка M1.1 (`browser.context`, `browser.page`, `browser.navigate`, `browser.observe`, `browser.query`, `browser.act`, `browser.download`, `browser.permission` версии 1.0) остаются **полностью неизменными**.

## 4. Independent Sources of Truth and State Ownership

Каждый домен обладает собственным изолированным источником истины (`Source of Truth`):

| Домен | Источник истины | Владелец | Персистентность |
|---|---|---|---|
| **Ресурсы движка** | `ContextId`, `PageId`, `DocumentRevision`, CEF HWND | `BrowserEngineProvider` | Установочное состояние провайдера (`installation state CAS`) |
| **Вкладки** | `TabId`, `TabGroupId`, порядок, закрепление, привязка к `PageId`, активная вкладка | `TabsService` | Транзакционное хранилище установки плагина вкладок |
| **История пользователя** | `HistoryEntryId`, URL, `NavigationId`, `PageId`, `DocumentRevision`, timestamp, заголовок | `HistoryService` | Транзакционное хранилище установки плагина истории |
| **Сессионная навигация** | Стек назад/вперед Chromium | CEF Engine | Внутреннее состояние процесса движка |
| **Транспорт событий** | Очередь доставки `EventEnvelope` | Kernel Event Transport | Оперативная память / логический журнал |

## 5. TabId vs PageId Semantics and Lifecycle Decoupling

1. **`TabId` — сервисная ссылка:** `TabId` идентифицирует вкладку в пользовательском интерфейсе. Вкладка ссылается на `PageId`, но не владеет им монопольно.
2. **Семантика закрытия вкладки (`Detach-only`):** Закрытие вкладки (`browser.tabs/close`) удаляет состояние вкладки из сервиса вкладок. Это **не закрывает** подлежащую страницу `PageId` в движке. Закрытие `PageId` требует отдельного авторизованного вызова `browser.page/close`.
3. **Согласование событий:** Сервис вкладок подписан на событие `browser.page.closed`. При получении факта закрытия страницы сервис детерминированно очищает осиротевшие ссылки на вкладки, не отправляя обратных команд закрытия.
4. **Восстановление после перезапуска:** При перезапуске плагина вкладок восстанавливается сохраненное состояние вкладок и сопоставляется с текущими доступными страницами движка; недостающие страницы не создаются фиктивно.

## 6. Engine Navigation vs Durable History Model

1. **Идемпотентная фиксация фактов:** При получении события `browser.navigation.committed` сервис истории сохраняет запись истории. Ключом идемпотентности является `NavigationId`.
2. **Дедупликация при повторной доставке:** Транспорт событий гарантирует доставку `at-least-once`. Повторная доставка события с тем же `NavigationId` и идентичными неизменяемыми полями обрабатывается как идемпотентный `no-op`.
3. **Конфликтующие дубликаты:** Попытка доставить событие с тем же `NavigationId`, но конфликтующими данными (другой URL или ревизия), приводит к явной ошибке целостности (`ConsistencyError`) и отвергается без перезаписи авторитетной записи.
4. **Обогащение заголовком без изменения стабильного события:** Событие `browser.navigation.committed` остается стабильным и не содержит заголовок. Заголовок страницы обогащается асинхронно при получении события `browser.page.ready` для соответствующей пары `(PageId, DocumentRevision)`.
5. **Изоляция удаления:** Очистка или удаление записей в сервисе истории модифицирует исключительно базу истории и не затрагивает куки, хранилище origins, профили движка или стек навигации Chromium.

## 7. Degraded Composition and Failure Isolation

Сервисы изолированы по сбоям:
1. **Авария сервиса истории:** Навигация и работа страниц в браузере продолжаются штатно.
2. **Авария сервиса вкладок:** Страницы движка `PageId` остаются работоспособными, доступными для прямых операций и визуализации.
3. **Авария движка:** Сервисы вкладок и истории сохраняют свои транзакционные данные и восстанавливают проекции после перезапуска провайдера.
4. **Конфиденциальность метрик:** Метрики и телеметрия сервисов вкладок и истории не содержат URL, тел страниц, введенных форм или значений cookie.

## 8. Planned M1.3 Bounded Service Bundle Sequence

Milestone M1.3 декомпозирован на строгую последовательность изолированных изменений:

1. **`C-BROWSER-TABS-HISTORY-SERVICES-20260901` (текущий):**
   Общая архитектура сервисов, экспериментальные контракты `browser.tabs/v0.1` и `browser.history/v0.1`, плагины вкладок и истории, проверочный срез S3A и CI suite `BrowserServices`.
2. **`C-BROWSER-DOWNLOADS-COOKIES-SERVICES-20260901`:**
   Сервис управления загрузками (артефакты, прогресс, назначение) и сервис инспекции/политики cookie/storage.
3. **`C-BROWSER-REQUEST-POLICY-ADBLOCK-20260901`:**
   Асинхронный перехват сетевых запросов, политики фильтрации контента, защита от рекурсии и fail-open деградация.
4. **`C-BROWSER-DIAGNOSTICS-SEARCH-SERVICES-20260901`:**
   Ограниченная диагностическая поверхность и сервис поиска с подключаемыми поисковыми системами.
5. **`C-BROWSER-SERVICES-S3-CLOSURE-20260901`:**
   Полная композиция всех сервисов M1.3, сквозной постоянный проверочный срез S3 и закрытие Milestone M1.3.
